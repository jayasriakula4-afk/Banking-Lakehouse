\# Component Responsibilities



| Component | Responsibility |

|-----------|----------------|

| RustFS | Object storage for Iceberg data files |

| PostgreSQL | Stores Polaris metadata |

| Apache Polaris | Iceberg REST Catalog |

| Apache Iceberg | Table format with ACID support |

| Apache Spark | Batch and streaming transformations |

| Apache Kafka | Streaming event platform |

| Apache NiFi | Batch ingestion and flow management |

| Dremio OSS | SQL query engine |

| Apache Superset | Visualization and dashboards |

| Apache Airflow | Workflow scheduling |

| Prometheus | Metrics collection |

| Grafana | Monitoring dashboards |

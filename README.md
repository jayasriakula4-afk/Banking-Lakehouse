\# 🏦 Banking Lakehouse



\## Project Overview



This project demonstrates how to build a modern Banking Lakehouse using 100% open-source technologies.



The platform supports:



\- Batch Processing

\- Real-Time Streaming

\- Medallion Architecture (Bronze, Silver, Gold)

\- Apache Iceberg

\- Apache Spark

\- Apache Kafka

\- Apache NiFi

\- Apache Airflow

\- Apache Polaris

\- RustFS (S3 Storage)

\- Dremio OSS

\- Apache Superset
